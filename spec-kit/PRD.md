# PRD (Product Requirements Document) — VLAST SHOP 웹 프로젝트

> **문서 버전**: v1.0  
> **기준 문서**: `spec-kit/AGENTS.md`  
> **타겟 사이트**: [https://vlastshop.com](https://vlastshop.com)  
> **문서 목적**: VLAST SHOP 웹사이트 클론 및 리팩터링 프로젝트의 제품 요구사항, 화면 구성, 기능 스펙 및 디자인 규격을 정의합니다.

---

## 1. 프로젝트 개요 (Product Overview)

### 1.1 프로젝트 목표
- 타겟 사이트(`vlastshop.com`)와 **디자인(시각적 외형·색상·글자·간격·인터랙션)은 100% 동일하게 재현**한다.
- 기존 복잡하고 파편화된 Cafe24 레거시 마크업을 탈피하고, **표준화된 3단계 박스 계층(겉박스 > `.inner-box` > 파티션 박스)** 기반의 모던 시맨틱 웹 레이아웃으로 내부 구조를 완전히 재구성한다.

### 1.2 핵심 개발 및 제품 원칙
1. **디자인 일치성**: 타겟 사이트의 보이는 결과(크기, 색상, 타이포그래피, 여백, 모션)를 충실히 구현한다.
2. **레이아웃 구조 혁신**: Cafe24 클래스나 마크업을 복사하지 않고, 자체 정의한 시맨틱 구조 규칙을 엄격히 준수한다.
3. **단일 진실 공급원 (SSOT)**: 모든 디자인 수치(색상, 간격, 폰트 크기, 반경, 그림자)는 CSS 변수(`tokens.css`)를 통해 중앙 집중 관리한다.
4. **점진적 향상 및 접근성**: 모바일 우선과 데스크톱 확장을 동시에 고려하며, 웹 접근성(WCAG 2.1 AA) 및 시맨틱 HTML5를 준수한다.

## 2. 기술 스택 및 시스템 제약사항 (Technical Constraints)

| 구분 | 기술 스펙 | 비고 및 제약사항 |
|---|---|---|
| **마크업** | HTML5 (시맨틱 태그 필수) | W3C 유효성 준수, 건너뛰기 링크, WAI-ARIA |
| **스타일** | Pure CSS3 (CSS 변수 기반 디자인 토큰) | 전처리기(Sass/Less) 및 CSS 프레임워크(Tailwind/Bootstrap) 사용 금지 |
| **스크립트** | Vanilla JavaScript (ES Modules, `type="module"`) | React/Vue 등 JS 프레임워크 및 외부 번들러(Vite/Webpack) 사용 금지 |
| **폰트** | Spoqa Han Sans Neo (Self-hosted woff2) | CDN 장애 대비 로컬 호스팅 서빙 (Regular 400, Medium 500, Bold 700) |
| **데이터 및 인증** | Firebase Cloud Firestore & 브라우저 LocalStorage | `community_posts`, `users`, `notices` 컬렉션 연동 |
| **지원 브라우저** | Chrome, Edge, Safari, Firefox 최신 2개 버전 | 모바일 iOS Safari 및 Android Chrome 완벽 대응 |

## 3. 정보 구조 및 화면 구성 (Information Architecture)

### 3.1 주요 페이지 구성
1. **메인 홈 (`index.html`)**: 프로모션 띠배너, 롤링 공지 배너, 100vh 반응형 히어로 배너, NEW ARRIVALS 상품 그리드, 푸터
2. **공지사항 게시판 (`notice.html`)**: 목록, 상세, 글쓰기, 글수정 4대 뷰 (관리자 권한 제어)
3. **커뮤니티 Q&A 게시판 (`community.html`)**: 6대 질문유형 선택, 비공개(비밀글) 보호, 관리자 공식 답변, 이모티콘 3종 반응 바
4. **상품 상세 (`detail.html`)**: 썸네일, 상품 옵션/가격, 수량 조절, CART(장바구니 담기) 인터랙션
5. **장바구니 (`cart.html`)**: 담긴 상품 목록, 수량 변경, 선택 삭제, 결제 예정 금액 합산 계산
6. **회원 인증 (`login.html`, `signup.html`)**: 관리자/일반회원 로그인, 회원가입 중복확인 및 프로필 동기화

### 3.2 글로벌 공통 영역 구조 (Global Layout)
- **3단계 계층 구조**:
  - **겉박스 (Outer)**: `header`, `main > section`, `footer` (너비 100%, 배경 및 섹션 패딩 담당)
  - **속박스 (Inner)**: `.inner-box` (단일 직계 자식, `max-width: 1920px`, 좌우 중앙 정렬 및 여백 제어)
  - **파티션 박스 (Partition)**: Flex 컨테이너 기반 가로/세로 분할 영역
  - **내용 박스 (Content)**: 카드, 텍스트, 폼 등 실제 UI 컴포넌트

## 4. 상세 기능 요구사항 (Functional Requirements)

### 4.1 프로모션 및 상단 안내 바
- **프로모션 바 (`.promo-bar`)**:
  - "첫 쇼핑을 지원하는 3,000원 할인 회원가입 쿠폰" 문구 링크 제공.
  - "오늘 하루 보지 않기" 체크박스 및 닫기 기능 (자정 만료 쿠키 연동).
- **상단 롤링 공지 띠배너 (`.top-notice-bar`)**:
  - 공지사항 상위 중요 글 3개를 3.5초 간격으로 한 줄 롤링 출력.
  - 일시정지, 재생, 닫기 버튼 및 페이지 인디케이터 제공.

### 4.2 헤더 & GNB (Global Navigation Bar)
- **유틸리티 라인 (PC 전용)**:
  - 언어 선택 (한국어, English, 日本語, 中文) 토글 메뉴.
  - 회원가입, 로그인/로그아웃, 주문조회, 최근본상품 링크.
  - 로그인 상태 실시간 동기화: `[사용자이름] 환영합니다` 문구 및 로그아웃 버튼 노출.
- **로고 및 쇼핑 메뉴**:
  - VLAST Shop 공식 로고 (홈 이동).
  - 상품 검색 열기 아이콘, 마이쇼핑 아이콘, 장바구니 아이콘 (실시간 수량 뱃지 연동, 0개일 때 숨김).
- **1뎁스 & 2뎁스 GNB**:
  - 카테고리: `ALBUM`, `MERCH`, `TOUR`, `SEASONAL`, `ASTERUM 433-10`, `NOTICE`, `COMMUNITY`.
  - MERCH, TOUR, SEASONAL 메뉴의 2뎁스 하위 아코디언/서브메뉴 제공.

### 4.3 메인 히어로 배너 (캐러셀)
- **전체 화면 반응형**: 데스크톱/태블릿/모바일에 맞춘 적응형 높이(`100vh` / `100svh`).
- **미디어 분리**: `<picture>` 태그를 활용해 데스크톱(`≥721px`)과 모바일(`≤720px`) 이미지 분리 서빙.
- **슬라이더 동작**:
  - 3장의 슬라이드 페이드(fade) 전환 (전환 속도 500ms, 자동재생 4000ms 간격).
  - 마우스 호버 시 자동재생 일시 정지.
  - 페이저(인디케이터 버튼), 이전/다음 탐색 버튼, 웹 접근성 준수를 위한 자동재생 정지/재생 컨트롤 제공.

### 4.4 NEW ARRIVALS 상품 목록 및 카드
- **그리드 레이아웃**: 데스크톱 기준 4열 배치 (`display: flex; flex-wrap: wrap;`), 모바일 2열 전환.
- **상품 카드 컴포넌트**:
  - 고품질 상품 썸네일 (`loading="lazy"` 적용).
  - 액션 아이콘: CART(장바구니 담기), WISH(관심상품 등록).
  - 상품명 (12px, `#555555`, 1줄 초과 시 생략 처리).
  - 판매가 표기 (`43,000원` 형태의 천 단위 콤마 및 통화 표기).
  - 품절(Sold Out) 상품의 경우 품절 뱃지 오버레이 및 장바구니 담기 비활성화.
- **더보기 인터랙션**:
  - "상품 더보기 (현재/전체)" 버튼 클릭 시 8개 단위 추가 로드.
  - 마지막 페이지 도달 시 버튼 자동 숨김 처리.

### 4.5 모바일 슬라이드 드로어 메뉴 & 하단 고정 내비게이션
- **모바일 드로어 (`.drawer`)**:
  - 햄버거 버튼 클릭 시 화면 좌측/우측에서 부드럽게 슬라이드 열림.
  - 상단 회원 정보 요약, 카테고리별 아코디언 서브메뉴, 고객센터, 언어 전환.
  - 드로어 오픈 시 배경 딤드 처리 및 본문 스크롤 잠금(`overflow: hidden`), `Escape` 키 닫기 지원.
- **하단 고정 바 (`.bottom-nav`, 모바일 전용)**:
  - 5개 핵심 탭: 전체 카테고리, 검색 열기, 홈, 장바구니(수량 뱃지), 마이페이지.
  - 우측 하단 맨 위로 이동(Top) 스무스 스크롤 플로팅 버튼.

### 4.6 검색 오버레이 레이어
- 검색 아이콘 클릭 시 상단에서 슬라이드 다운되는 풀스크린/상단 고정 검색창.
- 최근 검색어, 추천 태그, 실시간 검색어 닫기 및 키보드 `Escape` 지원.

### 4.7 공지사항 & 커뮤니티(답변형 Q&A) 게시판
- **공통 사양**:
  - VLAST 공식 핑크(`#e0245e`) 테마 및 통일된 테이블/카드 디자인.
  - 제목 검색, 기간별 검색, 페이지네이션 지원.
- **공지사항 특화**:
  - 상단 중요 공지 4종 고정 렌더링.
  - 관리자(`뚝스`, `admin`)만 글 작성, 수정, 삭제 가능.
- **커뮤니티 Q&A 특화**:
  - **질문 유형 6종**: `배송문의`, `교환/환불`, `계정문의`, `시스템오류`, `굿즈리뷰`, `기타`.
  - **비공개(비밀글)**: 체크 시 리스트에 `🔒 비공개` 표시, 상세 내용은 작성자 본인과 관리자만 열람 허용 (타인 열람 차단 및 잠금 안내 화면 제공).
  - **답변형 구조**: 리스트에 `답변완료` / `답변대기` 상태 뱃지 표출. 관리자만 질문 하단에 답변 작성/수정/삭제 가능.
  - **이모티콘 3종 반응**: 누구나 상세 페이지에서 `웃음(smile)`, `슬픔(sad)`, `좋아요(like)` 실시간 반응 클릭 가능.

### 4.8 회원 인증 및 권한 관리
- **회원가입**: 이름, 아이디, 비밀번호, 이메일 입력 및 중복 체크 검증 후 Firestore `users` 저장 (`role: 'user'`).
- **로그인/로그아웃**: 자격 증명 검증, 브라우저 세션 저장, 관리자(`뚝스`, `admin`, `role: 'admin'`) 권한 판별.

## 5. UI / UX 및 디자인 요구사항 (UI/UX Specifications)

### 5.1 반응형 분기점 (Breakpoints)
- **데스크톱**: `≥ 721px` (기본 뷰포트)
- **모바일 / 태블릿**: `≤ 720px` (모바일 전용 레이아웃 분기, 1열~2열 그리드, 모바일 헤더/하단바 전환)
- **최대 콘텐츠 너비**: `max-width: 1920px` (속박스 `.inner-box` 기준)
- **컨테이너 좌우 여백 (Gutter)**:
  - 데스크톱: `var(--inner-gutter, 2.5rem)` (40px)
  - 모바일: `var(--inner-gutter-mo, 1rem)` (16px)

### 5.2 타이포그래피 규칙
- **기본 폰트**: `'Spoqa Han Sans Neo', -apple-system, BlinkMacSystemFont, 'Segoe UI', sans-serif`
- **글꼴 두께**:
  - Regular: `400` (본문, 상품명, 일반 설명)
  - Medium: `500` (GNB 메뉴, 링크, 강조 본문)
  - Bold: `700` (제목, 가격, 주요 버튼)
- **주요 텍스트 크기 스펙**:
  - 메인 타이틀: `2rem` ~ `2.5rem` (32px ~ 40px)
  - 섹션 서브타이틀: `1.25rem` ~ `1.5rem` (20px ~ 24px)
  - 본문 기본: `1rem` (16px)
  - 상품명 / 판매가: `0.75rem` (12px, 상품명 `#555555` / 가격 볼드 `#008bcc` 또는 포인트 컬러)
  - 유틸리티 / 뱃지 / 캡션: `0.6875rem` ~ `0.75rem` (11px ~ 12px)

### 5.3 컬러 시스템 (Color Palette)
- **Primary Point Color**: `#e0245e` (VLAST 시그니처 핑크 - 버튼, 하이라이트, 활성 탭)
- **Secondary Accent Color**: `#008bcc` (타깃 사이트 가격 포인트 블루)
- **Neutral Colors**:
  - Background: `#ffffff` (기본 배경), `#f8fafc` / `#fafafa` (보조 배경)
  - Text Primary: `#111111` / `#222222` (본문, 헤드라인)
  - Text Secondary: `#555555` / `#666666` (상품명, 보조 설명)
  - Text Muted: `#888888` / `#94a3b8` (비활성, 캡션)
  - Border / Line: `#eeeeee` / `#e2e8f0` (구분선, 카드 테두리)

### 5.4 컴포넌트 터치 및 간격 규격
- **최소 터치 타겟**: 모바일 버튼 및 인터랙션 요소는 최소 `44px × 44px` 이상 확보.
- **버튼 스타일**: 라운드 반경 `4px` 또는 완전 타원형(`9999px`), 호버/포커스 시 명확한 피드백 제공.

## 6. 비기능 요구사항 (Non-Functional Requirements)

### 6.1 웹 접근성 (A11y — WCAG 2.1 AA)
- 최상단 **건너뛰기 링크(Skip Links)** 필수 제공 (`#category`, `#main`).
- 명도 대비: 텍스트와 배경 간 명도 대비 **4.5:1 이상** 준수.
- 모든 이미지 요소에 의미 있는 **`alt` 대체 텍스트** 제공 (장식용 이미지는 `alt=""`).
- 키보드 전용 사용자 지원: 모든 버튼, 링크, 입력창에 시각적 **포커스 링(`:focus-visible`)** 제공.
- 자동 재생 콘텐츠(슬라이더, 롤링 배너)에 **정지/재생 컨트롤** 필수 제공.

### 6.2 성능 및 최적화 (Web Vitals)
- **LCP (Largest Contentful Paint)**: 히어로 배너 이미지 preload 및 WebP/고효율 포맷 사용으로 2.5초 이내 로드.
- **CLS (Cumulative Layout Shift)**: 이미지 및 비디오에 명시적 `width`/`height` 또는 `aspect-ratio` 지정으로 레이아웃 흔들림 0.1 이하 유지.
- **스크립트 비차단**: 모든 모듈은 `type="module"` 또는 `defer` 속성으로 비동기 로딩.
- **네트워크 안정성**: Firestore 응답 지연에 대비한 타임아웃 레이스(Timeout Race) 및 로컬 스토리지 캐시 폴백 체계 유지.

### 6.3 검색 엔진 최적화 (SEO) & 메타데이터
- 각 페이지별 고유한 `<title>`, `<meta name="description">`, Open Graph(`og:title`, `og:image`, `og:description`) 설정.
- 시맨틱 랜드마크 태그(`header`, `nav`, `main`, `section`, `article`, `footer`)의 적절한 계층 구조 준수.

### 6.4 보안 및 데이터 무결성
- 사용자 입력 텍스트(제목, 본문, 작성자) 렌더링 시 **HTML 엔티티 이스케이프(`escapeHtml`)**를 적용하여 XSS(크로스 사이트 스크립팅) 공격 원천 방지.
- 비공개 글의 경우 클라이언트 측 단순 숨김이 아닌 권한 검증 분기를 통해 본문 마스킹.
