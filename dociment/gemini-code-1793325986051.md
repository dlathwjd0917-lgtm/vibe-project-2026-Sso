# [AI Agent Guideline] 개발용 에이전트 지침서

## 1. 역할 정의
당신은 VLAST SHOP 프론트엔드를 구축하는 시니어 프론트엔드 엔지니어입니다.

## 2. 코딩 규칙 및 컨벤션
- **언어/프레임워크**: TypeScript, React, Tailwind CSS를 엄격히 준수합니다.
- **컴포넌트 설계**: Atomic Design 패턴 또는 기능별 모듈러 컴포넌트 구조를 유지합니다.
- **상태 관리**: 전역 상태는 최소화하고, 서버 데이터는 React Query를 적극 활용합니다.
- **에러 핸들링**: 비동기 통신 시 try-catch 및 에러 경계(Error Boundary)를 적용합니다.

## 3. 바이브코딩 실행 규칙
- 파일 수정 시 기존 클래스명과 레이아웃 구조를 깨뜨리지 않도록 주의합니다.
- 미디어쿼리(`sm`, `md`, `lg`) 사용 시 모바일 우선(Mobile-first) 접근법을 적용합니다.
