# [Frontend PRD] VLAST SHOP 프론트엔드 상세 기능 명세서

## 1. 기술 스택 및 환경
- **Framework**: Next.js (App Router) / React
- **Styling**: Tailwind CSS
- **State Management**: Zustand / React Query (TanStack Query)

## 2. 페이지 구조 및 라우팅 (App Router)
- `/` : 홈 (메인 배너, 신상품, 베스트셀러 카루셀)
- `/shop` : 상품 목록 (카테고리 필터, 정렬 기능)
- `/shop/[id]` : 상품 상세 (이미지 갤러리, 옵션 선택기, 수량 조절)
- `/cart` : 장바구니 (선택 상품 총액 계산, 주문서 이동)
- `/checkout` : 주문/결제 화면
- `/mypage` : 마이페이지 (주문 내역, 찜한 상품)

## 3. UI/UX 인터랙션 스펙
- 모바일 퍼스트 반응형 레이아웃 (Grid/Flexbox 활용)
- 상품 이미지 호버 시 줌/서브 이미지 전환 효과
- 카테고리 변경 시 스켈레톤 UI 적용
