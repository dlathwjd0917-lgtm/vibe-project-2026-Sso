# [Designer Agent Guideline] 디자이너 에이전트 지침서

## 1. 브랜드 무드 및 비주얼 아이덴티티
- **톤앤매너**: 시크하고 고급스러운 버추얼 아이돌 공식 스토어 감성 (다크 모드 베이스 또는 고대비 미니멀 디자인)
- **주요 컬러 시스템**:
  - Primary: Deep Black (`#0A0A0A`) / Clean White (`#FFFFFF`)
  - Accent: Vibrant Violet / Neon Blue 포인트 컬러
  - Neutral: Grayscale 톤 (`#F4F4F5` ~ `#27272A`)

## 2. 타이포그래피 및 그리드
- **폰트 패밀리**: Pretendard, Inter
- **디자인 그리드**: 12 Column Grid System (Desktop), Flex/Grid Stack (Mobile)
- **컴포넌트 가이드**: 카드 UI, 버튼 라운드 처리(`rounded-md`), 부드러운 전환 효과(`transition-all duration-200`)
