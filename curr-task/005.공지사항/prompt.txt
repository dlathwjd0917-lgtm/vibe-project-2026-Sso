[ 공지사항 게시판 생성 프롬프트 ]
-첨부: 게시판 각 화면(4가지)
-프롬프트(원본):
첨부된 화면과 동일하게 공지사항 게시판을 만들거야. DB없이 로컬스토리지로 개발할거야.
 개발후 파이어베이스 DB로 마이그레이션 할 예정이야. 
 따라서 localstorage_to_firebase_guidelines.md 파일 지침에 따라 개발 구현해야해.

-프롬프트(수정:클로드)
첨부한 4개 화면(공지사항 목록 / 상세보기 / 글쓰기 / 글수정)과 동일한 UI와 동작으로 공지사항 게시판을 개발해줘.

[개발 조건]
- DB 없이 localStorage로 데이터를 저장한다.
- 개발 후 Firebase(Firestore)로 마이그레이션할 예정이므로, 반드시 localstorage_to_firebase_guidelines.md의 지침을 따라 구현한다.
- 지침의 핵심 원칙(데이터 접근 로직을 별도 Repository/Service 계층으로 
분리, 비동기(async/await) 인터페이스, 문서형 데이터 구조, 고유 ID 사용, 날짜는 ISO 문자열 저장)을 
지침 파일 내용과 충돌하지 않는 범위에서 지킨다. 충돌 시 지침 파일이 우선한다.
- UI 컴포넌트는 저장소 구현을 직접 호출하지 않고 Repository 인터페이스만 사용한다. (저장소 교체 시 UI 수정이 없어야 함)

[화면별 요구사항]
1. 목록: 총 건수, 분류(전체 등) 선택 + 검색, 글쓰기 버튼, 번호/제목/등록일/조회수 표, 중요공지 상단 고정(핀 아이콘·배경 강조), 
최근 글 NEW 뱃지, 페이지네이션(이전/다음 포함)
2. 상세: 중요/유형 뱃지, 제목, 등록일, 조회수, 본문(서식·링크 표시), 첨부파일 다운로드, 이전글/다음글 이동,
 목록으로/수정/삭제 버튼(삭제 시 확인창), 진입 시 조회수 +1
3. 글쓰기: 제목(필수), 공지유형 라디오(일반공지/이벤트안내/시스템점검/기타), 
첨부파일(최대 10MB, JPG/PNG/PDF/ZIP, 최대 5개), 
리치 텍스트 에디터(굵게·기울임·밑줄·취소선·글자색·배경색·정렬·목록·링크·이미지·표·서식제거·전체화면), 
글자수 카운터(0/5,000), 필수값 검증 후 등록
4. 글수정: 기존 데이터 불러와 채움, 첨부파일 변경/삭제, "수정일을 현재 날짜로 갱신" 체크박스, 목록으로/취소/수정완료 버튼

[기타]
- 헤더·푸터·브레드크럼 등 공통 레이아웃은 첨부 이미지와 같이 구성한다.
- 초기 확인용 샘플 데이터(이미지 속 목록 기준)를 시드로 제공한다.
- 첨부파일은 localStorage 용량 한계를 고려해 파일 메타데이터 중심으로 저장하고, Firebase Storage 전환 지점을 주석으로 표시한다.
- 구현 완료 후, 지침 준수 여부와 Firebase 전환 시 교체해야 할 파일/함수 목록을 간단히 정리해 알려준다.

[ 공지사항 구현후 연계 수정하기 ]
(1) 게시글 중 상위 3개 게시물을 별도의 박스로 구성하여 사이트 상단에 고정하고 한줄 출력하기.
 내용은 3개의 게시물이 순서대로 넘어감. (멈춤,플레이,닫기버튼 포함)

(2)공지사항 전체 제목이 모든 화면에서 왼쪽에 있어. 중앙으로 수정해. 
그리고 공지사항 리스트에 마우스 오버시 #ccc색으로 배경색 변경해.
 (거의 선생님 수정사항 내건 안되는 편)
    변경요청
    - index페이지에서 필요한 기능이야. notice에서는 제거하고 index로 옮겨. 
    그리고 notice 출력내용은 중앙정렬이야. 닫기버튼 등 컨트롤파트는 오른쪽 정렬이야. 

    추가수정 :
    상단고정 notice 출력박스의 디자인을 좀 변경할게. 왼쪽 '공지'는 'notice'라고 글자를 바꾸고 핑크색 라운드 버튼처럼 만들어줘.
    전체 배경색은 #222로 하고 글자색은 흰색으로 처리해.
    왼쪽 끝 컨트롤에서 멈춤버튼이 제일 이상해. 네모난 모양으로 넣어줘.

    추가수정 : 
    상단 notice박스가 닫으면 전체 아래 박스가 위로 올라와야하는데 지금 보면 메뉴만 위로 올라와.
    이 박스가 body 바로 아래 와서 전체 박스를 밀도록 해. 메뉴도 같이 밀려야하는 것은 기본이야.
    


[ 상세페이지, 장바구니 구현하기]   ----내거페이지에 맞게 프롬프팅 완료---
-첨부: 상세페이지 , 장바구니 페이지
-프롬프트(원본):
첫번째 화면은 상세페이지이고, 두번째 화면은 장바구니 이미지야.
메인페이지의 카드박스를 클릭하면 카드박스와 동일한 정보의 상품이 상세페이지가 셋팅돼.
그 정보는 json파일로 생성해서 처리해. 셋팅될 데이터는 이미지와 상품명 그리고 가격이야.
여기에 표시된 버튼 중 장바구니 버튼만 활성화하여 장바구니 페이지를 구성해.
상품 기본 정보를 표시한 리스트가 보이고 총 합계를 오른쪽 박스에 표시해.
이 정보는 모두 로컬스토리지에 저장하여 사용할 수 있게 해.
상품이 없을 경우 '선택한 상품이 없습니다'를 표시해.
그리고 장바구니에 상품이 담긴 경우 index페이지와 notice 페이지 등 
모든 페이지의 상단에 장바구니 아이콘 오른쪽 위에 검은색 원과 흰색숫자로 디자인된 표시가 나오게 구현해.
