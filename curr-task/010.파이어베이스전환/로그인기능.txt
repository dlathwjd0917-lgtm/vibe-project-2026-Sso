[ 로그인 / 회원가입 기능 만들기 ]
현재 사이트는 로그인 기능이 없어.
회원가입 기능과 더불어서 로그인 기능을 구현해.
회원가입 정보는 이름,아이디,비밀번호,이메일 까지만 받아서 중복체크 등 
기본기능을 구현해.
로그인 시 상단에 로그인상태를 표시해줘.(예 "플리 환영합니다")
로그인시에 변경될 변화는 현재의 공지사항의 글쓰기, 수정, 삭제 
기능을 admin에게만 준다는 것이야. 관리자 계정은 수동으로 등록해줘.
이름 : 뚝스
아이디 : admin
비밀번호 : 1111
이메일 : admin.com@company.co.kr

- 유의사항 :
로그인시 로그아웃 버튼으로 변경하여 활성화한다.
그리고 로그인버튼 클릭시 로그인 화면으로 가고 회원가입은 그 페이지 하단에
위치하게 해.

- 디자인:
공지사항(Notice) 화면을 기준하여 디자인해.


-수정사항
(1)로그인 페이지와 회원가입 페이지는 분리하고 
로그인 페이지 하단에 링크로 회원가입 페이지로 이동 할 수 있게 수정해.


1. 로그인 페이지(login.html)와 회원가입 페이지(signup.html)를 개별 페이지로 분리 완료.
2. 로그인 페이지 하단 카드에 '회원가입 페이지로 이동 →' 링크(signup.html)를 배치.
3. 회원가입 페이지 하단 카드에도 '로그인 페이지로 이동 →' 링크(login.html)를 배치하여 양방향 이동 지원.
4. 전용 스크립트 분리 (js/modules/login.js, js/modules/signup.js).
5. 회원가입 완료 시 가입된 아이디와 함께 로그인 페이지로 자동 전환되는 연동 로직 적용.
6. 상단 헤더 유틸리티 링크의 '회원가입' 주소를 signup.html로 일괄 동기화.
7. 로그인 상태 표시 시 사용자 등급 괄호표기((관리자), (플리)) 제거 완료 -> "{이름} 환영합니다"로 깔끔하게 단일 표시.
8. 사용자 회원 정보(회원가입, 로그인, 관리자 계정)를 Firebase Firestore의 'users' 컬렉션에 실시간 저장 및 자동 동기화 완료.


[ 수정구현 ]

[ 추가변경요청 ]
-현재 상단과 하단의 공통 모듈이 각 페이지에 하드(날)코딩되어 있어.
이 부분을 하나로 만들고 모듈화하여 페이지별로 관리하지말고 
한곳에서 제어하도록 수정해.

[ 작업완료내역 ]
1. 사용자 필드 스펙 규격화 (authService.js):
   - 일반회원: role: 'user', 관리자: role: 'admin' 반영 완료.
   - 필수 필드: createdAt(ISO 문자열), email(문자열), name(문자열), 
   role('admin'|'user'), username(문자열), id, password.
   - Firestore 'users' 컬렉션 문서로 저장 및 동기화.
2. 상·하단 공통 모듈 중앙 집중화 (js/components/siteLayout.js 신규 모듈):
   - getHeaderTemplate(), getBottomNavTemplate(), getFloatingUITemplate(), 
   getFooterTemplate(), initSiteLayout() 구현.
   - 사이트 전체 6개 페이지(index.html, notice.html, cart.html, detail.html, 
   login.html, signup.html)에 적용 완료.
   - 각 페이지에 수백 줄씩 중복 하드코딩되던
    상단 헤더, 모바일 바텀 내비, 플로팅 버튼, 푸터 마크업을 제거하고 
    단일 파일(siteLayout.js)에서 일괄 렌더링 및 제어.
   - initAuthHeader()(로그인/환영문구), initCartBadge()(장바구니 수량), 
   탑버튼 스무스 스크롤 자동 통합 연동.
